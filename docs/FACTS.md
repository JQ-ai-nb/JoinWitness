# 项目事实参考（AI 辅助整理）

| --- | --- |
| 维护者 | 蒋琦 / JQ-ai-nb；其联系方式、参赛经历、队友信息未假定 |
| 新项目 | 原创 MoonBit 等值关联预检，与旧调度及 robots 项目业务不同 |
| 场景一 | 数据工程师发现订单关联客户后重复计数；定位多租户单键冲突，导出三行反例，比较复合键后匹配变化 |
| 场景二 | 设备数据接入人员定位未匹配记录；区分 NULL、类型差异与真正缺失设备，依据完整对表核验覆盖率 |
| 场景三 | 迁移维护者检查新旧键；即使输出都为两行，也能发现所有原始匹配均被替代，补足 count 回归的盲区 |
| 核心 | 四种 JOIN、组合键、精确类型与 NULL、基数／覆盖率／预算、反例核验、行对差分、受保护的结果构造 |
| 核心实现 | MoonBit，Node 处理文件和适配，浏览器展示结果，无第三方 npm 包依赖 |
| 验证 | 35 项 MoonBit 测试、11 项 Node 集成测试、SQLite 320 组完整集合、真实 Chromium、多平台 CI |
| 身份 | Git 作者和提交者统一为蒋琦及账户专属 noreply 邮箱；GitHub owner 和模块命名空间为 JQ-ai-nb |
| 范围 | 每表最多 10000 行，等值关联，精确原始类型；不解析任意 SQL，不猜测业务键是否正确 |
